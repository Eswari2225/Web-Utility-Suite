About AzureStay

AzureStay is a demo front-end for a hotel management system. In a full implementation, it would connect to a backend API for booking, check-in/out, payments, inventory and reports. The layout here is created to be easy to integrate with any server-side technology (Node.js, Django, PHP, Java Spring, etc.).

  • Room catalogue & booking
  • Quick booking form
  • Guest contact collection
  • Admin login (placeholder)
